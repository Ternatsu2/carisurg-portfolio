Deployment requirements at a glance

Shadow-mode pilot | version 1.0

EHR, monitors and optional HRI draft

Source, time and device state remain visible.

→
Nurse input review

Correct, validate or continue manually.

→
Versioned model request

One ESI suggestion; no direct write permission.

→
Nurse decision and audit

Confirm or override through the authorised EHR workflow.

The model response cannot write the final ESI. Only an authenticated nurse action can close the decision loop.

Functional

  • Provenance and stale-data review
  • Required-field validation
  • Confirm, override and correction
  • No-action escalation without auto-triage
  • HRI consent, read-back and erase

Non-functional

  • P95 response target at or below 2 seconds
  • WCAG 2.2 AA and multimodal access
  • Role-based access and encryption
  • Append-only audit events
  • Physical safety and cleaning lockout

Verification

  • Interface contract tests
  • Fault injection and downtime drills
  • Nurse scenario testing
  • Accessibility, privacy and security review
  • ESI 1, subgroup and override monitoring
